## 🚀 نصب

> پیش‌نیاز: لینوکس (**روت**)، اوبونتو / دبیان، و ترجیحاً پنل روی **همان** سرور.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SiNaKeEn/NexusNet-Node/Multi/install.sh)
```

دستور `nxt-node` نصب می‌شود و منو باز می‌شود. دفعات بعد:

```bash
sudo nxt-node
```

نام‌های قدیمی هنوز کار می‌کنند: `nexusnet`، `NexusNet`، `panel-tools`.

<details>
<summary><b>اگر خطای <code>Argument list too long</code> دیدید</b></summary>

```bash
curl -sL "https://raw.githubusercontent.com/SiNaKeEn/NexusNet-Node/Multi/install.sh" -o /tmp/install.sh && sudo bash /tmp/install.sh
```
</details>

<details>
<summary><b>پیشنهاد سخت‌افزار</b></summary>

| مورد | پیشنهاد |
|------|---------|
| سیستم‌عامل | Ubuntu 20.04+ / Debian 11+ |
| CPU / RAM | حداقل ۲ هسته · ۴ گیگ |
| لوکیشن سرور | **آلمان** یا **هلند** برای Exit تور بهتر است |
| پنل | ثنایی، پاسارگارد یا مرزبان روی همان ماشین |
| دسترسی | Root (`sudo`) |

کیفیت پینگ نهایی به اینترنت کاربر و مسیر تور هم بستگی دارد.
</details>

### خط فرمان

```bash
nxt-node                 # منوی تعاملی
nxt-node health          # یک‌بار همه نودها (اگر مشکلی باشد exit code ۱)
nxt-node health de --geo # یک کشور + چک کشور خروجی
nxt-node health --json
nxt-node bot setup       # اتصال بات تلگرام
nxt-node bot status|start|stop|restart|logs|test
nxt-node panels
nxt-node update
```

## 🤖 بات سلامت تلگرام

### راه‌اندازی

1. [@BotFather](https://t.me/BotFather) → ساخت بات → کپی **توکن**  
2. [@userinfobot](https://t.me/userinfobot) → کپی **آیدی عددی**  
3. `nxt-node` → **۱۷** → **۱** و هر دو را وارد کنید

یا:

```bash
sudo nxt-node bot setup
```

### دستورهای بات (فقط ادمین)

| دستور | کار |
|-------|-----|
| `/status` | وضعیت و پینگ همه نودها |
| `/down` | فقط نودهای مشکل‌دار + دلیل |
| `/ping [cc]` | بررسی زنده |
| `/node de` | جزئیات: سرویس، پورت، bootstrap، IP خروجی |
| `/restart [cc]` · `/restart_all` | ریستارت (برای «همه» تأیید می‌گیرد) |
| `/newnym cc\|all` | مدار جدید تور |
| `/system` · `/ip` | آپتایم، لود، رم، دیسک · IP سرور |
| `/settings` · `/mute 60` · `/unmute` · `/interval 120` | کنترل هشدار |

زبان پیام‌ها هنگام راه‌اندازی انتخاب می‌شود (فارسی / English).

## 🧩 Panel Tools

`nxt-node` → **۱۶** (یا `nxt-node panels`).

برای هر نود ساخته می‌شود:

**اینباند** (کلون از مبدأ) → **اوت‌باند SOCKS** به `127.0.0.1:<پورت نود>` → **قانون روتینگ** → **هاست**

| پنل | روش | نکته |
|-----|-----|------|
| **ثنایی** | API + دیتابیس محلی | |
| **پاسارگارد** | API | یوزر/پسورد یک‌بار ذخیره می‌شود |
| **مرزبان** | API | یک ریستارت Xray برای هر تعداد نود؛ تگ‌ها `NexusNet-XX` |

قانون ایمنی: اینباندهای شخصی شما **هرگز** پاک یا بازنویسی نمی‌شوند. حذف فقط با تطبیق دقیق تگ است.

## 📦 جریان کار معمول

1. **نصب موتور** (منو `1`)  
2. **افزودن نود** — تکی (`4`) یا گروهی (`5`)  
3. **Panel Tools** (`16`) — کلون اینباند و هاست  
4. **بات** (`17`) — اختیاری برای هشدار و ریستارت از راه دور  
5. **تأخیر / ریستارت / بکاپ** در صورت نیاز

حذف در گزینه `7` از این ورودی‌ها پشتیبانی می‌کند:

```
1          → یک نود
1,3,5      → چند نود
1-10       → بازه
```

## 🔒 امنیت

| موضوع | رفتار |
|-------|--------|
| بایند SOCKS | پیش‌فرض فقط **127.0.0.1**. برای پنل ریموت: `NXT_SOCKS_BIND=0.0.0.0` **و فایروال** |
| رمزها | توکن بات و پسورد پنل در `/etc/nexusnet/` |
| دسترسی بات | فقط آیدی‌های ادمین |
| حذف پنل | فقط تگ دقیق NexusNet |

## ❓ سوالات پرتکرار

<details>
<summary><b>از نسخه ۲ آپدیت کنم؟</b></summary>
همان دستور نصب را بزنید. نودهای موجود دست‌نخورده می‌مانند. دستورهای قدیمی کار می‌کنند.
</details>

<details>
<summary><b>پینگ بالاست (۲۰۰–۲۵۰)؟</b></summary>
بیشتر به مسیر شبکه و مدار تور بستگی دارد. سرور <b>آلمان</b> یا <b>هلند</b> معمولاً بهتر است. ریستارت نودها مدار تازه می‌گیرد.
</details>

<details>
<summary><b>هاست روی پاسارگارد ساخته نشد؟</b></summary>
API پاسارگارد فیلد <code>address</code> را به‌صورت لیست می‌خواهد. نسخه‌های جدید NexusNet همین فرمت را می‌فرستند — آپدیت کنید.
</details>

<details>
<summary><b>منوی بات خودش می‌آید / دکمه‌ها کار نمی‌کنند؟</b></summary>
بعد از setup: <code>sudo nxt-node bot restart</code>. آیدی عددی تلگرام را در لیست ادمین چک کنید و یک‌بار داخل بات <b>Start</b> بزنید.
</details>
